Help & Installation

Important: no automatic syncingEach device (phone or computer) keeps its own invoices and works independently, offline. Invoices do not sync between Android and Windows. To move records, use Backup → Export on one device, send the file (WhatsApp, email, USB), then Backup → Restore on the other.

Android phone (Chrome)

  1. Open the app link in Google Chrome while online and wait for it to load fully.
  2. Tap the ⋮ menu (top right).
  3. Tap Install app (or Add to Home screen), then Install.
  4. Open Yan Biyu from your home screen. It starts with a splash screen and works offline.

Windows 10/11 – Google Chrome

  1. Open the app link in Chrome while online.
  2. Click the install icon at the right of the address bar (or ⋮ → Cast, save and share → Install page as app).
  3. Click Install.
  4. Launch it from the Desktop or Start menu. Right-click its icon to pin to the taskbar.

Windows 10/11 – Microsoft Edge

  1. Open the app link in Edge while online.
  2. Click … → Apps → Install this site as an app (or the install icon in the address bar).
  3. Click Install, and allow the Desktop / Start menu shortcuts.
  4. Launch it from the Desktop or Start menu.

Tip: use SHARE PDF on an invoice to send it by WhatsApp or email from Android. On Windows use DOWNLOAD PDF or PRINT INVOICE.
